### Before installation

PigeonPod is a media downloader and feed generator. Confirm that the YunoHost host has enough persistent disk space for the media library you intend to keep.

Use a dedicated domain or subdomain for the application. The current frontend is not packaged for arbitrary YunoHost subpaths.

The initial upstream account uses the documented default credentials `root` / `Root@123`. Change that password immediately after the first login.
